| Structure | |
|---|---|
| ai-identification/ | posts checked for AI, sorted by verdict + detector results |
| corpus/ | instagram posts, 19 account folders, 6,206 posts + captions, on-image text, subtitles |
| cited-examples/ | Examples as referenced in thesis footnotes |
| one-nation/ | One Nation across all platforms + their website (has self contained corpus & ai-identification) |
| pipeline/ | configuration and scripts |
| Codebook A (Policy Topic).pdf | policy topic coding handbook - how posts were coded for themes |
| Codebook B (Visual Register).pdf | visual register coding handbook - subjects + predication |
| raw_data_workbook.xlsx | assorted items - urls, AI verdicts, detector scores, PHON listings, video measurements, etc. - nothing in here (possibly very minimal) is referenced directly in thesis |
| thesis_data.xlsx | coded data, figures and tables, most data referenced from thesis is stored here  |
| viewer.zip | theme coding kit for human coders - viewer, 16 sample posts and blank coding sheet, instructions inside |
